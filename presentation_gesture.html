Domain 1 — Digits

Ten air-drawn digits (0–9). Gestures are essentially planar; inter-user variability mainly in the out-of-plane (z) component. Dataset from Huang et al. (2019).

Domain 4 — 3D Geometric Figures

Ten 3D shapes (Cuboid, Cylinder, Sphere, Rectangular Pipe, Hemisphere, Cone, Cylindrical Pipe, Pyramid, Tetrahedron, Toroid). Intrinsically three-dimensional; harder cross-user generalization.

Synthetic example trajectory — \(\mathbf{r}(t) = [x(t),\, y(t),\, z(t)]^\top \in \mathbb{R}^3\)

Each gesture is a discrete time series of 3D coordinates recorded by a depth sensor:

\[\mathbf{r}(t) = [x(t),\; y(t),\; z(t)]^\top \in \mathbb{R}^3, \quad t = 1,\ldots,T\]

Two cross-validation protocols are used throughout:

  • User-independent — leave-one-user-out (10 outer folds). Tests generalization across people.
  • User-dependent — leave-one-sample-out per user per gesture. Tests within-person discrimination.

Methods

Dynamic Time Warping (DTW)

k-NN classifier variable-length sequences from-scratch implementation

Finds the optimal non-linear alignment between two sequences by minimizing cumulative Euclidean distance via dynamic programming. Local cost: \(d(i,j)=\|\mathbf{x}_i - \mathbf{y}_j\|_2\).

\[D(i,j) = d(i,j) + \min\begin{cases}D(i-1,j-1)\\D(i-1,j)\\D(i,j-1)\end{cases}\]

Three path constraints:

  • Boundary: path starts at (1,1) and ends at (N,M).
  • Monotonicity: both index sequences are non-decreasing.
  • Continuity: transitions only between adjacent cells — no observation skipped.

Edit-distance on quantized sequences

k-means vector quantization Levenshtein distance k-NN
3D points → k-means (K clusters) → symbol string → Levenshtein distance → k-NN
\[D(i,j) = \min\begin{cases}D(i-1,j)+1 & \text{(deletion)}\\D(i,j-1)+1 & \text{(insertion)}\\D(i-1,j-1)+c(i,j) & \text{(substitution, }c=0\text{ if equal, else }1\text{)}\end{cases}\]

Hyperparameter grid: K ∈ {15, 20, 25, 30, 35, 40} compression ∈ {True, False} k ∈ {1, 3, 5, 7} PCA ∈ {none, 2D, 3D}

compression = False optimal across all settings: consecutive repeated symbols still carry local timing information — compressing them discards discriminative signal.

Three-Cents recognizer (Caputo et al., 2018)

rotation-free 3D adaptation of $1 1-NN
Resample to n pts → Scale by arc-length L → Translate to centroid → 1-NN template match
\[L = \sum_{i=1}^{n-1}\|\mathbf{r}'_{i+1}-\mathbf{r}'_i\|_2, \qquad \mathbf{r}''_i = \frac{\mathbf{r}'_i}{L}\] \[D(C,T) = \frac{1}{n}\sum_{i=1}^{n}\|\mathbf{c}_i - \mathbf{t}_i\|_2\]

Rotation step of $1 removed: in 3D, no canonical reference angle exists — Golden-Section Search becomes geometrically ambiguous and computationally expensive.

Hyperparameter grid: n_points ∈ {16, 32, 64} PCA ∈ {none, 2D, 3D}

n = 16 optimal (not 64): short mid-air trajectories — denser resampling introduces interpolation noise without new geometric information.

Bidirectional LSTM

end-to-end learned early stopping batch normalization
\[\mathbf{f}_t = \sigma(\mathbf{W}_f\mathbf{x}_t + \mathbf{U}_f\mathbf{h}_{t-1}+\mathbf{b}_f) \quad \text{(forget gate)}\] \[\mathbf{i}_t = \sigma(\mathbf{W}_i\mathbf{x}_t + \mathbf{U}_i\mathbf{h}_{t-1}+\mathbf{b}_i) \quad \text{(input gate)}\] \[\mathbf{o}_t = \sigma(\mathbf{W}_o\mathbf{x}_t + \mathbf{U}_o\mathbf{h}_{t-1}+\mathbf{b}_o) \quad \text{(output gate)}\] \[\tilde{\mathbf{c}}_t = \tanh(\mathbf{W}_c\mathbf{x}_t + \mathbf{U}_c\mathbf{h}_{t-1}+\mathbf{b}_c)\] \[\mathbf{c}_t = \mathbf{f}_t \odot \mathbf{c}_{t-1} + \mathbf{i}_t \odot \tilde{\mathbf{c}}_t\] \[\mathbf{h}_t = \mathbf{o}_t \odot \tanh(\mathbf{c}_t)\]

Offline task → BiLSTM justified: full trajectory available before classification. Early stopping: patience = 5, 10% validation split per fold. Model re-initialized at every fold (no leakage).

Cross-validation protocol

Leave-one-user-out — 10 outer folds (one held-out user per fold). Tests generalization to entirely unseen users.

Leave-one-sample-out per user per gesture — 10 outer folds. For each user, one repetition per gesture class is held out as test. Tests within-person discrimination.

Data-leakage prevention All preprocessing transformations — z-score normalization (mean & std), k-means centroids, and PCA components — are fitted exclusively on the inner-train set. They are applied without refitting to inner-val and to the test fold. The test fold is never seen during hyperparameter selection.
